# 开源前安全检查（2026-08-28）

## 结论与范围

当前工作区已经修复本次确认的管理员鉴权绕过及若干相关风险，可以作为待发布候选版本。**不代表线上实例已修复，也不代表可以跳过下方发布前确认直接公开旧版本。** 本次没有部署、推送、修改仓库可见性或重写 Git 历史。

检查对象为本地工作区（包含审查开始前已有的大量未提交改动）及本地全部可达 Git 引用：39 个提交、181 个历史文件版本。覆盖认证/会话、管理接口、上传处理、存储键与路径、SQLite 查询、备份恢复入口、构建产物、Git/Docker 排除规则、CI 及依赖。既有功能改动保留，没有回滚为旧架构。

## 已确认并修复

| 严重程度 | 问题与证据 | 修复与验证 |
| --- | --- | --- |
| 严重 | `server/auth.ts` 通过普通对象的真值判断会话。隔离复现中，伪造 `session_id=__proto__`、`constructor`、`toString` 均令受保护端点返回 200，而随机无效值返回 401。未登录者可绕过管理权限。 | 使用独立 SQLite 中的会话令牌哈希查询、服务端过期和外键撤销；HTTP 回归确认这些值不能访问上传、回收站、任务或用户信息。没有对真实图库执行攻击。 |
| 高 | 登录回调未关联浏览器发起的请求，无 `state` / PKCE；授权判断只比较邮箱，没有验证邮箱归属或完整配置。 | 已替换为内置 Passkey，移除 OIDC 回调及第三方身份配置。SimpleWebAuthn 校验签名、精确 Origin/RP ID、UV 和管理员 user handle；挑战绑定浏览器与用途，五分钟过期且验证前单次消费。首个管理员须持有 CLI 生成的十分钟一次性令牌；真实签名的合成凭据测试覆盖并发抢注、重放和校验失败。 |
| 高 | Cookie 虽有七天寿命，服务端会话却永久有效；旧会话不会因管理员或身份服务变更失效；默认会话文件权限和并发写入也不明确。 | 服务端七天过期；拒绝旧 Cookie；认证目录 `0700`、数据库 `0600`，会话和初始化令牌仅保存 SHA-256 哈希。SQLite 事务处理凭据、会话和挑战；持久化失败不签发 Cookie。增删密钥需单次新鲜验证，删除密钥撤销关联会话；CLI reset 改变账户代次并撤销所有凭据、会话与在途请求。 |
| 高/中 | 锁文件包含 ExifReader、Hono、XML 解析器和开发工具依赖的已知告警。并非每条告警的特定功能都被本项目使用，但图片元数据解析位于真实上传链路。 | 更新 ExifReader 4.44.0、Hono 4.13.5、ESLint 9.39.5 及间接依赖；`flatted` 使用兼容 3.x 安全版本约束，锁定 3.4.4；最终 `bun audit --json` 返回 `{}`、退出码 0。 |
| 中 | Vite 默认文件服务没有额外阻止会话、数据库、备份文件。 | 添加 `server.fs.deny`，测试常规路径与 `/@fs` 路径都返回 403；开发后端默认监听回环地址；补全 `/media` 代理。不要把敏感文件放进故意公开的 `public/`。 |
| 中 | 原 CI 通过 SSH 执行远程部署且关闭主机密钥校验。 | 已移除该远程部署入口，验证与发布权限分离；维护者需撤销不再使用的部署凭据。 |
| 中/加固 | 退出登录使用 GET；身份响应未明确禁止缓存；原 CSRF 默认校验不覆盖 JSON，且反向代理需要明确的公开 Origin。 | 退出改为 POST；身份及管理响应 `private, no-store`；所有非安全方法额外检查已提供的 Origin/Fetch Metadata，并以 `BASE_URL` 为准。认证写操作必须提供精确 Origin；其余 JSON 管理 API 仍允许无 Origin 的非浏览器客户端；没有启用跨域凭据 CORS。 |

- 全量 `bun test`：91 通过、0 失败（838 个断言）（包括新增认证测试和扩充的 HTTP/开发服务器测试）。测试仅使用合成照片、临时数据库、合成 Passkey 密钥对和回环 HTTP/S3 服务；沙箱不允许监听端口，获准后在沙箱外运行。

- `git diff --check` 与 `sh -n entrypoint.sh` 通过。原图路径校验、SQL 参数绑定、队列/像素限制、共享资产删除及备份恢复沿用现有实现并通过回归测试。

- [ ] 在实际 HTTPS 域名上设置 `BASE_URL`，用自己的设备完成 CLI 初始化、注册、登录、添加备用密钥、删除密钥、退出及重启测试，并演练停机后的 CLI 恢复。域名变更需要重新注册，旧 OIDC 会话不会迁移。

## 边界与后续建议

未扫描无法从本地引用到达的远端历史、已删除远端引用、外部 CI 日志/密钥、线上数据库、实际照片、S3 权限、Bun 原生解码器或容器 OS 漏洞。浏览器已检查初始化/登录页面、无效令牌提示和未登录的安全设置页；尚未在真实设备上验证指纹、系统 Passkey 同步、硬件密钥或已登录的密钥管理界面，也没有生产部署或负载/渗透测试。密钥扫描是启发式检测，不能证明所有秘密都不存在。

当前不配置完整 CSP，前端使用外部字体；如部署要求更严格的浏览器隔离或禁止第三方请求，应增加并实测 CSP、考虑自托管字体。上传队列和像素限制不是完整的资源耗尽防护；登录状态虽限制总数，仍需部署侧限流。认证 SQLite 与图库 SQLite 独立。默认部署仍是单应用进程；分布式多实例需要额外设计数据库共享、限流和部署约束。
